# Proyecto Python

Este proyecto está desarrollado en **Python 3.11.9** usando **VSCode** y utiliza las siguientes librerías:

- PyQt5 — Para interfaces gráficas.
- SQLite3 — Base de datos integrada en Python.
- Scikit-learn — Para machine learning y análisis de datos.
- Matplotlib — Para gráficos y visualización de datos.

---

# Requisitos

- Python 3.11.9
